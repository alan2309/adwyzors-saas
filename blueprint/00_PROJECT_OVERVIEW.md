# Adwyzors ERP SaaS

## Vision
Build a configurable, multi-tenant ERP SaaS for manufacturing, trading, wholesale and retail businesses.

## Principles
- Multi-tenant
- API-first
- Engine-driven architecture
- Event-based inventory ledger
- Configurable workflows
- RBAC
- Audit logging
- Modular
- Enterprise scalability

## Tech Stack
- Next.js
- TypeScript
- PostgreSQL + Prisma
- Redis
- BullMQ
- Docker
- DigitalOcean
